模型后端

两种后端：云端 API直连任意 OpenAI 兼容平台（耗 token）；WorkBuddy 桥接完全不联网，把 prompt 交给 WorkBuddy 跑、把结果贴回，最省 token。主流厂商（DeepSeek / 智谱 / 通义 / Kimi / 商汤 / 火山…）都用 OpenAI 兼容协议，切服务商 = 换接口地址 + 模型名 + Key 三项。

桥接模式无需 Key、不联网。运行 AI 精读时，公告页「桥接」面板会列出待处理 prompt；复制到 WorkBuddy 运行、把 JSON 贴回即可。点「测试连接」会直接显示「桥接就绪」。

终端 空闲

本机命令行窗口（仅 127.0.0.1 可访问），可直接跑 pip / python 等指令。 ⚠ 等同于在本机打开的命令行，请自行甄别，勿跑破坏性指令。少量高危指令（如 rm -rf / format / shutdown）会被拦截。
