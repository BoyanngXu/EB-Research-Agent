# 可交换债数据总表：合并重建

## 输入与输出

输入 —— 日期目录下必须齐备这 4 个文件（脚本会自动规范化带日期后缀的文件名）：

| 文件 | 来源 |
|------|------|
| `上证固收成交明细.xlsx` | 手工从固收平台导出 |
| `可交债.xlsx` | 手工从 Wind 导出（标的基础信息 + 排序依据） |
| `现券交易信息（逐笔）.xlsx` | **eb-data-download** 自动下载（深交所） |
| `中证可交换债券估值.xlsx` | **eb-data-download** 自动下载（xxxxx） |

输出 —— `<日期目录>/可交换债数据.xlsx`，15 列：

```
日期 | 证券代码 | 证券名称 | 正股代码 | 正股简称 | 成交金额（万元） | 成交量(张) |
成交均价（净价） | 票面利率(当期参考%) | 补偿利率（%） | 转股价格(元) | 正股收盘价(元) |
中证含权估值(元) | 期权价值(元) | 中证不含权估值(元)
```

行规则：**有成交的标的每笔成交一行，无成交的标的单行列出**；标的按 `可交债.xlsx` 中的顺序排列。

## 用法

```bash
pip install -r requirements.txt

python scripts/可交换债数据.py 20260817                 # 相对日期目录（相对 --base）
python scripts/可交换债数据.py D:\Data\20260817         # 完整路径
python scripts/可交换债数据.py --base D:\Data           # 指定日期目录的根，交互选日期
python scripts/可交换债数据.py 20260817 --no-template   # 不套模板，纯数值表
```

Windows 双击 `运行.bat`，macOS/Linux 执行 `运行.command`。
已有旧版总表会先存档到 `.analysis/<日期>_可交换债数据_旧版_<时间戳>.xlsx` 再重建，不会丢。

## 模板机制

`模板/` 目录里放了一份带外部链接公式的成品总表 + 4 个源文件样本。脚本优先套用它，
这样生成的表**保留公式联动**（改源文件后 Excel 里刷新即可重算）。

找不到任何模板时（全新环境），脚本自动降级：生成**纯数值表**，数值全对，只是没有公式。
想强制走这条路加 `--no-template`。

模板查找顺序：`模板/` → `--base` 下各日期目录里最近修改的 `可交换债数据.xlsx`。

## 关键实现点（改动前必读）

这几条都是从真实数据事故里总结出来的，不是洁癖：

1. **行结构动态生成**，不依赖固定行位。早期版本按固定行号写，某天某只债成交笔数变多
   就整体错位、产生垃圾行。现在按 `可交债.xlsx` 标的顺序逐只展开。
2. **全部字段按证券代码前 6 位 VLOOKUP**，不依赖源文件行号对齐 —— 各行顺序变化完全无感。
3. **表外成交必须剔除**：只保留出现在 `可交债.xlsx` 表内的标的成交，否则可转债
   （如申能转债）会混进可交换债表里。这是最容易漏的一条。
4. **B 列代码补后缀**：裸 6 位数补 `.SZ`，已有 `.SH/.SZ` 保留；先 TRIM 去尾随空格再判位数
   （源文件里带尾随空格会导致 `LEN()=6` 判断失效）。
5. **写缓存值 + `fullCalcOnLoad`**：外部链接没刷新时也能直接显示正确数据，重算也正确。
   这是通过直接改写 `xl/worksheets/sheet1.xml` 的 `<v>` 节点实现的。
6. **F/G/H 三列为 0 或空时整格留空**，不写公式不写缓存值 —— 无成交标的的金额列应该空白而非 0。
7. **公式错误值（`#NAME?` / `#N/A`）按空处理**，避免 Wind 公式尚未重算时污染输出。

## 排错

- **「缺少源文件」** → 检查 4 个文件是否齐全、文件名是否带日期后缀（脚本会自动重命名，
  但目标文件已存在时会跳过并提示）。
- **输出行数明显偏少** → 大概率 `可交债.xlsx` 里标的缺失，表外成交被规则 3 剔掉了。
- **输出行数明显偏多** → `可交债.xlsx` 里混入了非可交换债标的。
- **金额对不上** → 注意成交量单位：现券逐笔的 F 列是「手」，要 ×100 才是「张」。
