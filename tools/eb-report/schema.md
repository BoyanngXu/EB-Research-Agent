# 晨会分享结构化标注 Schema v0（全量口径）

背景：`C:\Users\<用户名>\Desktop\Report\` 下《晨会分享YYYYMMDD.docx》为研究员晨会口播稿的留存整理。已抽取为 UTF-8 txt（每行 `序号\t段落文本`）。你的任务：对分配给自己的每篇 txt 精读全文，按本 Schema 输出**严格 JSON**。禁止臆造文档中没有的信息；拿不准宁可留空/标记。

## 输出文件
一个 UTF-8 JSON 文件，顶层为**数组**，元素顺序与分配文件顺序一致：
```
[
  {主记录1}, {主记录2}, ...
]
```

## 主记录字段（每篇 1 个对象）

| 键 | 类型 | 说明 |
|---|---|---|
| date | str | 8位日期，取文件名 YYYYMMDD，如 "20260515" |
| paras | int | txt 段落数 |
| chars | int | 正文字符数（不含行号） |
| speaker | str | 从开头识别"我是×××"，识别不到填 "" |
| themes | list[str] | 一级主题大类，见词表，**最多标 4 个**（该篇真正主打的） |
| modules | list[str] | 内容模块：用原文自然标题/主题短语概括，每条 ≤15 字，如 ["宏观速览","MLCC缺货复盘"] |
| core | str | 核心增量信息：事件式要点 80~300 字，只写"新信息/边际变化/明确结论"，不写背景常识。多板块则按板块分句 |
| targets_n | int | 提及明确标的名（公司/产品可数主体）的去重数 |
| forecasts | list[obj] | 可提取的明确预测/指引/观点判断，每条 obj {scope, item, kind} |
| risks | list[str] | 文档明示或强推的担忧/风险点，每条 ≤25 字，无则 [] |
| sources | list[str] | 引用的外部信源/机构，如 "招商机械"、"天风"、识别不到填 [] |
| quality | list[str] | 质量问题标记，命中下列情形才写，否则 [] |
| stocks | list[obj] | 标的明细，见下，**全篇提及的有效标的都收**，宁多勿漏 |

### forecasts[].kind 枚举（只能取其一）
`业绩` / `资本开支/产能` / `估值/股价` / `供需/价格` / `政策/事件` / `海外动态`
- scope：主体（公司/板块/事件），item：判断内容（含数字与时间点，≤60 字），摘录式凝练。

### risks 示例
"光模块龙头受FCC制裁担忧压制" / "涨价传导受阻于消费客户" / "高利率压制资本开支赛道估值"

### quality 标记枚举（按需填 0~2 个）
- `疑似重复草稿`：同一内容前后两遍（如速览版+详解版）
- `疑似历史复盘/旧闻`：内容明显是过去时段复盘而非当日新讯
- `疑似截断`：结尾突兀/明显不完整
- `演讲者缺失`：无"我是×××"开场
- `仅标题/极简`：正文过短信息量低

## 标的明细 stocks[].obj

| 键 | 类型 | 说明 |
|---|---|---|
| name | str | 标的名（公司中文名/简称；海外公司如 SK海力士、英伟达；产品主体如"SpaceX"） |
| sector | str | 细分板块（自有词，≤6 字），如 光模块/存储/MLCC/燃机/算电协同/注塑机 |
| dir | str | 方向枚举：`强推` `推荐` `关注` `提示风险` `负面` `中性` `仅提及` |
| logic | str | 核心逻辑摘要 ≤40 字 |
| anchor | str | 预测锚点/量化数据（估值、增速、订单额、时间点），无则 ""，≤40 字 |
| quote | str | 关键原文摘录（逐字），≤50 字，找不到贴切短句则留 "" |

## themes 一级大类词表（标大类，最多 4）
- `宏观与政策`：利率/CPI/美联储/中美关系/国内政策
- `AI软件与应用`：AI应用、办公Agent、AI剧/传媒内容、大模型、SaaS
- `算力硬件`：光模块/光通信、GPU/AI芯片、服务器、IDC/算电协同、散热、连接、PCB/CCL、光纤光缆、存储
- `半导体`：设备/材料/晶圆代工/设计/封测/载板
- `电子元件涨价链`：MLCC、电阻电容、电子布/铜箔等涨价主题
- `电力与新能源`：缺电/燃机/柴发/变压器/HVDC/核电/光伏/储能/风电
- `高端制造`：机械/通用设备/顺周期/商业航天/卫星/低空/机器人/汽零
- `医药与AI4S`：创新药、CXO、AI4S、生物科技
- `其他`：未覆盖内容（尽量不用）

> 划分原则：存储归"算力硬件"；PCB/CCL/MLCC 涨价逻辑归"电子元件涨价链"，属AI基建算力则并标"算力硬件"；燃机柴发变压器归"电力与新能源"；机器人/商业航天归"高端制造"。

## 写作纪律
1. core 事件式：数字、同比、上修/下调、时间点必须保留。
2. 同一主体同时有强推与风险提示：stocks 给主体当前主导方向 dir，logic 里带出两面，risks 里单独列风险。
3. 全篇重复出现同一标的只收 1 条明细（合并最全信息）。
4. "提及标的"不表态也收，dir 填 `仅提及`（正文角色为主语即可）。
5. 海外宏观主体（如"美联储"）不算 stock。
